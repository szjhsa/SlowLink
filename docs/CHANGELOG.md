# 更新日志

## [1.1] - 2026-10-01

- 当前主线和插件版本统一改为 1.1。
- 包含插件类型、规则生成、去重兼容、CPU 超时保护和插件关闭回退的全部修复。
- 发布构建只允许清理仓库 `dist`，拒绝删除其它已存在目录。
- 插件安装会预编译规则正则，并使用唯一临时目录；插件切换失败时自动回滚。
- 修复插件类型标签转义和 URL hash 直达页面，统一简化版控制台。
- 抽奖参与人数等动态指纹改由插件 `dynamic_line_patterns` 定义，跨模板冲突保留正文去重 key。
- 新增 `code_identity` 插件协议，支持掩码/明文注册码的双向识别，核心仅在发送成功后提交身份。
- 插件改为只做码识别、分类和去重增强，不再独立触发转发；没有用户正则时不会自动匹配业务消息。
- 插件明确判定为说明文或开奖结果时，即使用户正则命中也不会转发。

## [1.0] - 2026-08-15

- 首个正式纯净版：主程序不再内置规则插件，安装后为纯净引擎，插件由用户上传。
- 插件支持上传、启用、停用、删除、同 ID 更新，上传插件持久化保存，更新后不丢失。
- 正则、排除文本、码识别、去重、账号/转发/监听、备份恢复、日志和 watchdog 全面整理。
- 支持正则单条启用/停用、修改后台密码、登录失败锁定、配置导入失败自动回滚。
- 正则列表按钮在桌面和手机端保持紧凑布局，长正则自动换行不遮挡操作按钮。
- Caddy 异常退出或配置损坏时会自动用当前配置重建，更新脚本也会重建非运行状态的 Caddy。
- Caddy 增加 Docker 健康检查，`manage.sh status` 直接显示代理健康状态。
- 新增 `manage.sh doctor` 一键检查容器、健康、插件、磁盘和公网访问。
- Redis 增加 256MB 内存上限和 `volatile-lru` 淘汰策略。
- watchdog 每天自动清理 Docker 构建缓存；备份目录只保留最近 7 份。
